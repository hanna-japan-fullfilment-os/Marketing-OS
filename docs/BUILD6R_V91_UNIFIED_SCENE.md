# V9.1 unified premium scene foundation

The dark cinematic/headline–hero–callouts reference class now goes through
`compose_unified_scene` before final HTML rendering. It plans the product,
approved text roles, brand zone, lighting intent, depth and negative space as
one provider-neutral specification. Other reference classes keep legacy paths.

Prepared canonical product placement and asset identity remain constraints.
The composer never redraws, relocates or grants asset approval. Source copy,
claim provenance, type minima and the existing 20 structural checks remain.
Impossible copy/placement must fail those checks; intent is not proof of fit.

Four archetypes capture the approved V7/V8 evidence: editorial hero for rich
storytelling, spotlight for wide packages, diagonal flow for feature stories,
and atmospheric product stage for sparse layered scenes. Selection uses role,
aspect ratio, approved-copy amount, callout count and reference depth.

The scene resolves shared story-axis and sequential text constraints and a
product-anchored brand zone. Its `layout` is the existing `LayoutSpec`, used by
the renderer probe and frozen QA. Complete scene and layout digests persist
alongside the original slide contract and survive render-context enrichment.

Premium text defaults to transparent support over planned contrast zones.
Actual background contrast must still pass QA. Legacy opaque panels remain
available only to the legacy composition interface. The brand uses canonical
logo pixels: existing transparency is retained, or a connected near-white
border matte alone becomes transparent (all border channels >=250, chroma <=5).
Enclosed whites and RGB artwork remain intact. The source file remains
unchanged. Unsupported backgrounds retain pixels in a source-supported zone;
they are not automatically recolored or reconstructed.

Five ordered depth slots are modeled. Grounding plane, contact/ambient shadow,
halo, light direction, product illumination, text contrast and falloff are
explicit intent for subsequent design/art-layer builds. New shadows, 3D effects,
decorative accents and a perceptual cohesion evaluator are **not rendered or
claimed proven in V9.1**. Active existing layers and future intent are labeled.

Sparse content selects atmosphere/product prominence without manufacturing
benefits, CTA or claims. The canonical V8 failure remains a visual failure;
synthetic geometry/HTML tests do not establish a postable image. No provider,
GPU, final cover or carousel is invoked by this build.
